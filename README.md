# Retail Data Engineering Platform

## Project Overview
An end-to-end data engineering project built using Azure Databricks, PySpark, SQL, and Delta Lake. This project processes retail e-commerce data through a Medallion Architecture to create reliable and analytics-ready datasets.

## Business Scenario
An e-commerce business receives data related to customers, orders, products, payments, and sellers. The objective is to build a scalable data pipeline that ingests, cleans, transforms, and processes this data to support business analytics and decision-making.

## Architecture
- **Bronze:** Raw data ingestion and source preservation.
- **Silver:** Data cleansing, standardization, deduplication, and transformations.
- **Gold:** Business-level aggregations and analytics-ready datasets.

## Technology Stack
- Azure Databricks
- Python
- PySpark
- SQL
- Delta Lake
- Unity Catalog
- Lakeflow Jobs
- Git & GitHub

## Project Goals
- Build an end-to-end data pipeline using Medallion Architecture.
- Implement data ingestion and transformation using PySpark.
- Implement incremental data processing.
- Implement SCD Type 1 and SCD Type 2.
- Orchestrate pipeline tasks using Lakeflow Jobs.
- Implement data quality checks.
- Create analytics-ready Gold datasets.
